## Limits of this evaluation

- One snapshot of one feed on one afternoon. Only 8 of the 113 real records mention pedestrians at all, so recall is estimated from very few positives.
- Labels were assigned by the same developer that built the system (the team's AI coding agent), without a second annotator, and they are not blind: several of the labelled records had already been run through the assessor during development. Treat the headline figure as a consistency check, not an independent benchmark.
- Unlisted records were labelled not actionable by keyword screen, so a pedestrian effect phrased without any of the screened words would be mislabelled.
- This measures the judgment step only. Location matching, expiry and the baseline-journey gate are covered by the deterministic tests in `tests/`.
